## 記事構成案

前回（SM真夏3社比較）と同じ型を踏襲しつつ、ドラッグストア特有の要素を加える。

### 構成

1. **リード文** — 秋の風邪予防シーズン。DgSの売場が最も変わる時期。しかし現場を歩くと…
2. **DgS・A店（大手チェーン）** — メーカー標準什器＋定番POPの展開。整っているが「記憶に残らない」理由を考察
3. **DgS・B店（中堅チェーン）** — 手書きPOPや独自の「推し棚」展開。なぜ手書きは刺さるのか？
4. **DgS・C店（地域密着or独自路線）** — 全館テーマ型の「風邪予防フェア」。SM版C店と同じ構造の成功パターン
5. **まとめ：3つの鉄則** — 前回記事との共通法則を抽出（横串の知見）
6. **おわりに** — CTA（DMでの相談誘導、マガジンフォロー誘導）

### 前回との差別化ポイント

- **業態変更**: SM → DgS（読者のカバー範囲を拡大）
- **DgS特有の論点**: 
  - 医薬品売場のPOP規制（薬機法の表現制限）と販促の工夫
  - カウンセリング売場 vs セルフ売場でVMDの作法が異なる
  - メーカー什器（定型）vs 店舗オリジナルPOP（手書き）の効果差
- **法規制への言及**: 健康訴求・効果効能表現の注意点（リーガル検品で要チェック）

## フィールドリサーチ計画

### 対象店舗の選定基準

- 都内のドラッグストア3社（異なるチェーン・異なる規模）
- 以下から3社を選定：
  - 大手：マツモトキヨシ / ウエルシア / ツルハドラッグ
  - 中堅：サンドラッグ / スギ薬局 / セイジョー
  - 地域密着：クリエイトSD / トモズ / その他

### 取材時期

- **9月中旬〜9月下旬**（秋の風邪予防商材の売場展開が本格化する時期）
- 平日昼間の来店推奨（混雑回避・売場をじっくり観察するため）

### 撮影ルール

1. **個人の顔は絶対に写さない**（他の客・スタッフ）
2. **店舗名・ロゴが特定されるものはぼかし処理**（A店・B店・C店表記）
3. 売場全体（どの棚か分かる引き）と、POP・什器のアップをセットで撮影
4. NG例がある場合は、改善提案とセットで記載（批判だけで終わらない）
5. 撮影前に店舗スタッフに声をかけてOKをもらう（グレーな場合は外観のみ）

### チェックポイント（取材メモ用）

各店舗で以下を記録する：

- [ ] 風邪予防・免疫カテゴリの売場面積（棚数・エンド数）
- [ ] メーカー什器の種類と設置場所
- [ ] 手書きPOP・オリジナルPOPの有無と内容
- [ ] 関連陳列（クロスマーチャンダイジング）の有無
  - 例：マスク×のど飴、ビタミンC×ドリンク
- [ ] 全館テーマ展開の有無（統一POPが複数売場に横断しているか）
- [ ] 価格訴求 vs 価値訴求のバランス
- [ ] 健康訴求の表現（薬機法・景表法の観点でメモ）
